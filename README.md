# Акты сервисных работ

Офлайн-приложение (PWA) для iPad и телефона: форма → предпросмотр → DOCX / PDF акта «Акт о проведении сервисных работ».
Все данные (заказчики, акты, сотрудники) остаются в браузере устройства и никуда не отправляются. В этом репозитории только код.

## Публикация на GitHub Pages (один раз)

1. На github.com: **New repository** → имя `akt-app` → **Public** (бесплатные Pages работают только для публичных репозиториев) → без README, .gitignore и лицензии → **Create**.
2. В папке `akt-app` выполнить (подставьте свой логин и свои имя/почту для коммита):

   ```powershell
   cd "D:\Yandex.Disk\GearProduction\Акты выполненных работ\akt-app"
   git config user.name "Ваше Имя"
   git config user.email "you@example.com"
   git commit -m "Первая версия"
   git remote add origin https://github.com/<ЛОГИН>/akt-app.git
   git push -u origin main
   ```

   Если запрашивается вход, GitHub открывает окно авторизации в браузере (или используйте Personal Access Token вместо пароля).
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `/ (root)` → Save**.
4. Через 1–2 минуты адрес появится вверху той же страницы: `https://<ЛОГИН>.github.io/akt-app/`.

## Установка на устройства

Открывать адрес нужно с интернетом, один раз.

- **iPad / iPhone (Safari):** кнопка «Поделиться» → **На экран «Домой»** → Добавить.
- **Honor (Chrome или браузер Honor):** меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).

Затем откройте приложение с иконки, включите авиарежим и убедитесь, что форма открывается и акт собирается без сети.

## Первый запуск

1. Вкладка **Сотрудники** → добавить инженеров (ФИО как в подписи, должность). Список общий для всех актов на этом устройстве.
2. Проверить поле «Производитель» там же.
3. Вкладка **Акт** → заполнить → **Просмотр акта** → **DOCX** или **PDF**.
   - PDF собирается прямо в приложении и скачивается файлом (iPad: откроется просмотр, оттуда «Поделиться» → «Сохранить в Файлы»). PDF — это картинка страниц из просмотра, текст в нём не выделяется.

## Обновление приложения

1. Изменить файлы, в `sw.js` увеличить номер версии (`const V = "akt-v1"` → `"akt-v2"`).
2. `git add -A && git commit -m "..." && git push`.
3. На устройстве открыть приложение два раза: первое открытие скачивает обновление, второе его применяет.

## Важное

- **Данные на устройстве:** список сотрудников, архив и черновик лежат в памяти браузера. Очистка данных сайта их удаляет. Делайте **Архив → Экспорт** время от времени. Файл переносит данные и на другое устройство (Импорт).
- Приложение, добавленное на экран «Домой», сохраняет данные надёжнее, чем вкладка Safari: Safari может стереть данные сайта, которым не пользовались около недели.
- **Не добавляйте в репозиторий** файлы экспорта (`akt-backup-*.json`) и готовые акты: репозиторий публичный. `.gitignore` уже блокирует `*.json`, кроме манифеста.
- **Диктовка (кнопка микрофона)** использует распознавание речи браузера. Звук при этом обрабатывается сервером Apple или Google. Чтобы этого избежать, диктуйте микрофоном на клавиатуре.
- Шаблон акта собирается кодом в `gen.js` по образцу `Акт о проведении сервисных работ YKZ7250A.docx`. Любые правки макета (поля, ширины колонок, число строк) делаются там.
